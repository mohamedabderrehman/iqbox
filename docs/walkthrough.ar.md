# جولة موثقة

جولة في لقطات فعلية للواجهة. ليست فيديو متصلاً أو فحص جهاز موبايل. ينفذ أمر القبول تسلسل الخادم ببيانات اصطناعية؛ راجع سجل التحقق.

رفع من أندرويد بعد الدخول ← حفظ الملف وبياناته في الخادم ← إنشاء رمز مشاركة ← عرض عام وبوابة الإعلان ← بث أو تنزيل؛ تدير اللوحة المنصة.
