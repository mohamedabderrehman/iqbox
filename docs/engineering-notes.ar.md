## من رفع أندرويد إلى صفحة مشاركة عامة

يجمع IQBox تطبيق Kotlin وJetpack Compose وAPI Express وقاعدة PostgreSQL وعارض PHP ولوحة React. يوضح جمع هذه الواجهات حدود الرفع والمشاركة: تبقى ملكية الملف الخاص لدى API المصادق عليها، ويتيح رمز مشاركة مولد العثور عليه في العارض العام. لا ينبغي أن يمنح الرابط حذف الملف أو الوصول لمجلدات أخرى.

لذلك تشمل الفحوص مجلد مستخدم آخر والحذف غير المصرح والرموز غير الصالحة والملفات القابلة للتنفيذ وحدود التخزين. يحتاج العارض عنوان API يصل إليه الخادم، يختلف عن عنوان محاكي أندرويد. يعيد موجه PHP محلي صغير إنتاج روابط /file و/folder دون إعداد VPS.

## فصل مسارات المنتج عن متطلبات المزودين

تتضمن الشيفرة بوابات الإعلان وحساب المشاهدات والاشتراكات والإحالات والمحفظة والسحب. هذه مسارات هندسية ولا تثبت إيرادات أو اتصال خدمة دفع. تبقى أزرار المتجر مخفية حتى ضبط رابط حقيقي، ويحدد العرض العام أن ملفه مولد.

كشف فحص الإدارة خطأ أثناء التحميل الأول: لم تكن الإحصاءات مهيأة عند عرض عداد المجلدات. أتاح إصلاحه عرضاً متصلاً لقاعدة جديدة وقائمة الملفات والعارض العام. تبقى الرفوع الخلفية على الأجهزة وسياسة تكرار المشاهدات وانتقالات المزود أولويات التحقق التالية.
